# Gizmo design

A gizmo is a small device that does one thing. Start by deciding what the one thing is, and
write it down before touching any part of the design.

## Sizing

Choose the size from the load it carries. A gizmo that is too large wastes material, and one
that is too small fails under use.

- Measure twice.

## Finishing

Finish the surface last, after every test has passed.
