# Sample rules

MUST NOT is a defect. SHOULD NOT needs a stated reason.

## Widgets

- MUST NOT paint a widget twice in one frame.
- MUST NOT cache a widget by its position;
  use its identity instead.
- SHOULD NOT nest widgets deeper than three levels.

## Gadgets

- MUST NOT leave a gadget unplugged.
- SHOULD NOT reuse a gadget across threads.

```text
## not a heading, inside a fence
```

## Doodads

- MUST NOT name a doodad after a person.
